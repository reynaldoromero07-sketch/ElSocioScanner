# ElSocioScanner 🚗💨

**ElSocioScanner** es una aplicación de diagnóstico automotriz desarrollada en Python. El sistema está diseñado para conectarse a interfaces de hardware OBD-II (ELM327) mediante conexiones seriales o Bluetooth, permitiendo la lectura, análisis y despliegue de datos críticos del vehículo en tiempo real.

## 🛠️ Características Principales

* **Interfaz Móvil Multiplataforma:** Desarrollada con Kivy para ofrecer una experiencia fluida tanto en dispositivos móviles como en escritorio.
* **Conectividad OBD-II:** Integración nativa con la librería `obd` de Python para comunicarse con la ECU (Unidad de Control Electrónico) del automóvil.
* **Monitoreo en Tiempo Real:** Visualización de parámetros esenciales del motor como RPM, velocidad, temperatura del refrigerante y códigos de falla (DTC).

## 🚀 Tecnologías Utilizadas

* **Python 3**
* **Kivy Framework** (Interfaz Gráfica)
* **Python-OBD** (Protocolo de comunicación automotriz)
